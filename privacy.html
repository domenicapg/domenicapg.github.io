Privacy Policy — Hermes Personal Backup

Last updated: 2026-11-17

Hermes Personal Backup ("the Tool") is a private, single-user automation script operated by its owner for the owner's own Google account. The Tool is not offered to the public and has no other users.

1. Google user data accessed

When the owner grants consent, the Tool may access the following data in the owner's own Google account, limited to the scopes the owner approves:

  • Gmail — read messages and create/send drafts on the owner's behalf.
  • Google Drive — create and manage files in the Tool's own backup folder.
  • Google Calendar — read and create events.
  • Contacts — read the owner's contacts to resolve recipients.
  • Google Sheets / Docs — read and write documents the owner opens with the Tool.
  • Google Tasks — read and create tasks.

2. How the data is used

Data is used solely to perform the actions the owner requests through their own assistant: writing backups, drafting mail, reading the owner's schedule and notes, and recording tasks. No advertising, profiling, or analytics is performed.

3. Storage and transfer

OAuth credentials and the resulting data are stored only on the owner's own machine and in the owner's own Google Drive account. Backups are encrypted with AES-256 before upload; the encryption key never leaves the owner's machine. No Google user data is transmitted to, stored on, or processed by any third-party server operated by the Tool's author.

4. Sharing

Google user data is never sold, rented, or shared with third parties. It is not used for training machine-learning models and is not used to determine creditworthiness or for lending.

5. Limited Use

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

The owner may revoke access at any time at myaccount.google.com/permissions, and may delete stored data by removing the local token file and the backup folder in Drive. Revoking access immediately invalidates the Tool's credentials.
