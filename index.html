Hermes Personal Backup

The purpose of this application is simple: to keep an encrypted backup of the owner's own Hermes assistant data in the owner's own Google Drive, automatically and without any other person being involved.

This page is public information about the application. No sign-in, account or login is required to read it. This site is not a login page and does not contain any login form. It exists only to describe what the application does and how it handles data.

What this application is

Hermes Personal Backup is a private automation tool that runs on a single computer owned and operated by one individual. It is used only by that individual. It is not sold, not distributed as a product or service, and it has no other users. It does not run a public server and it does not store Google user data on any server.

Why it exists (purpose)

  • The owner runs a personal assistant program called Hermes that stores configuration, conversation history and scheduled-job data locally.
  • If that computer fails, that data would be lost.
  • This application therefore packs that data into an AES-256 encrypted archive every day and uploads the encrypted archive to a private folder in the owner's own Google Drive, so it can be restored later.

What it does, step by step

  1. Collects the owner's Hermes configuration and data files on the local machine.
  2. Compresses them into a single archive and encrypts it locally with AES-256 (openssl enc -aes-256-cbc). Encryption happens before anything leaves the machine.
  3. Uploads only that encrypted archive to one private Google Drive folder that belongs to the same Google account.
  4. Deletes old archives on a rolling schedule (7 daily + 4 weekly copies are kept).
  5. Optionally lets the assistant read and draft the owner's own Gmail messages, calendar events, contacts and documents, purely so the assistant can answer the owner's own requests (for example: "summarise today's mail"). No one else's data is ever accessed.

Data it touches

  • Google Drive — writes the encrypted backup archives into one private folder.
  • Gmail — reads and drafts the owner's own mail when the owner asks the assistant to.
  • Calendar / Contacts / Docs / Sheets / Tasks — reads or edits the owner's own items only, when the owner asks.

Full details, including retention, what is never done, and how to revoke access, are in the Privacy Policy and the Terms of Service.

No. The OAuth client is used by exactly one person (the owner). Access to the application is not offered to anyone else, there is no sign-up flow, and there is no multi-tenant service behind it.

日本語での説明

このアプリの目的

このアプリケーションの目的は、所有者本人の Hermes アシスタントのデータを、所有者本人の Google ドライブに暗号化して自動バックアップすることです。利用者は所有者1人のみです。

動作の流れ

  • 所有者のコンピュータ上で、設定・履歴・スケジュールデータを1つにまとめます。
  • AES-256 でローカル暗号化します（暗号化はアップロード前に完了します）。
  • 暗号化済みアーカイブのみを、同じ Google アカウントの非公開ドライブフォルダにアップロードします。
  • 古いアーカイブはローテーションで削除します（日次7世代・週次4世代）。
