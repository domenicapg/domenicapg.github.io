Hermes Personal Backup

This is a personal, single-user automation tool. It runs on its owner's own machine and connects to the owner's own Google account to keep an encrypted backup of the owner's Hermes assistant data in Google Drive.

What it does

  • Creates a local, AES-256 encrypted archive of the owner's Hermes configuration and data.
  • Uploads that archive to a private Google Drive folder owned by the same account.
  • Optionally reads Gmail, Calendar, Contacts, Sheets, Docs and Tasks on behalf of the owner so the assistant can draft messages and read the owner's own schedules and notes.

The tool is not distributed, has no other users, and does not operate a server that stores Google user data. See the Privacy Policy.
